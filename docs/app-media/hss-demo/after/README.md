# Remedy: after surgery (recovery at home)

Setup: iPhone 18 Pro Max simulator (iOS 27), light mode, demo scenario `hssKnee` (made-up patient Ruth Callahan, right total knee replacement Thu Nov 12, all data fake). Main set: `demoPlanDay 4` at `-demoTime 14:00` (Monday Nov 16, day 4). `later-*` set: `demoPlanDay 14` at `-demoTime 11:00` (Thursday Nov 26, day 14).
